# Exercicio 1 - Dicionario de dados

Neste exercicio foi realizada a analise da configuracao das tabelas do projeto conforme a apostila.

O dicionario de dados contempla:

- Tabelas SZ1 e SZ2 cadastradas no SX2 em modo Compartilhado.
- Campos das tabelas configurados no SX3, respeitando tipo, tamanho e contexto (Real ou Virtual).
- Indices configurados no SIX:
  - SZ1: Z1_FILIAL + Z1_CODIGO
  - SZ2: Z2_FILIAL + Z2_CONTAT + Z2_SEQUEN
- Dominio SX5 "Z2" contendo os tipos de interacao:
  - E
  - L
  - R
  - V
  - W
